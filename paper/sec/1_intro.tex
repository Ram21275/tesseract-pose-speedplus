\section{Introduction}
\label{sec:intro}

Many applications need the 6D pose of a \emph{known} object from a single image: a robot picking a part from a bin, an inspection station checking the orientation of an assembly, a warehouse arm grasping a product, or a servicer spacecraft approaching a target. Each application brings its own objects, cameras, lighting and training data. Today, adapting a pose estimator to a new object or domain typically means fine-tuning a large network, which is costly in data, compute and engineering, and has to be repeated for every new application. Foundation backbones offer an alternative: their features already encode appearance and 3D geometry well enough that, in principle, they could be shared and kept frozen, with only a small downstream head trained for each new object. This paper asks:

\begin{quote}\itshape
Can shared frozen appearance and geometry backbones support accurate 6D pose estimation across different object types through compact, inexpensive-to-train downstream heads?
\end{quote}

We study this with a modular architecture. A frozen DINOv3~\cite{simeoni2025dinov3} backbone supplies appearance tokens and, optionally, a frozen MoGe-2~\cite{wang2025moge2} backbone supplies surface-normal tokens. A standard interface pools these into fixed-size token grids, and per-object heads read them: a hierarchical rotation tree that predicts a path in a tesseract partition of $SO(3)$~\cite{kurz2017tesseract}, and a translation block that reads the same encoded tokens. The two branches are fused per tree level by a training-free product of experts (PoE)~\cite{hinton2002poe}. We call this design \emph{plug-and-play} in a narrow sense: a new object reuses the backbones, the feature interface, the head architecture, the training recipe and the inference algorithm, and only its heads are trained, which takes minutes. It is \emph{not} zero-shot: each object needs labelled training images in a fixed object frame, camera intrinsics, a crop (a ground-truth box or a trained detector), and its symmetry set if it is symmetric, and the heads of one object do not transfer to another. A few inference options (geometry fusion, orbit aggregation) are chosen per application on validation data.

The main difficulty for such small heads is \emph{selecting} the right mode. A symmetric object has several rotations that produce the same image, all of them correct; a nearly symmetric object has look-alike rotations of which only one is correct; and under a domain shift the details that separate them become unreliable. Distributional pose methods~\cite{murphy2021implicitpdf,haugaard2023spyropose,hsiao2024liepose} can represent such multi-modal posteriors, but a single prediction still has to select a mode. Hierarchical hypotheses make this selection explicit, and we address it at three points: \emph{training} targets that cover all symmetry-equivalent rotations (\cref{sec:symtarget}); \emph{orbit aggregation} at test time, which scores the tree's candidates for consistency across in-plane rotations of the crop through an exactly derived camera-roll transform (\cref{sec:orbit}); and \emph{orbit distillation} of that consistency into single-view students (\cref{sec:distill}).

We evaluate the same architecture on three general-object benchmarks that stress different kinds of difficulty: textureless industrial parts with continuous and discrete symmetries (T-LESS), exactly symmetric solids (SYMSOL-T) and cluttered household objects (YCB-V). We then apply it unchanged to a demanding downstream application, spacecraft pose estimation for autonomous rendezvous under a synthetic-to-real shift (SPEED+~\cite{park2022speedplus}). The other applications named above motivate the design but are not evaluated here. All configurations are selected on validation data, all criteria were fixed before the runs, and results that rely on ground-truth crops or ground-truth translation are labelled as such.

Our contributions are as follows. (1) A reusable 6D pose architecture in which frozen, shared foundation backbones (0.30\,B and 0.33\,B parameters) feed per-object rotation and translation heads of 2.1--2.4\,M and 0.33\,M parameters, trained in a median of 5--16 minutes each from cached features; we report the full adaptation and inference cost, including feature extraction and, where needed, detector training (\cref{sec:interface,sec:cost}). (2) A hierarchical rotation head whose size does not grow with the number of rotation hypotheses (131,072 leaves, 44 nodes scored per greedy decode), which is far more accurate than a flat classifier over SPACE-HOP's 131,076-anchor Hopf grid under the same recipe ($3.87^\circ$ vs.\ $7.53^\circ$) with $15\times$ fewer parameters; a same-grid control that would separate the effect of hierarchy from that of the grid is still running (\cref{sec:abl_flat}). (3) Symmetry-aware multi-path supervision for hierarchical rotation trees, which improves T-LESS at every recall threshold (orbit R@10 $73.5\%\to79.0\%$) and every SYMSOL-T shape ($2.62^\circ\to2.07^\circ$), and which, unlike canonical labels, keeps orbit aggregation effective (\cref{sec:general,sec:abl_sym}). (4) Orbit aggregation with an exact roll transform for hierarchical candidates and its distillation into single-view students: aggregation lowers validation error on T-LESS, SYMSOL-T and SPEED+ at about $4\text{--}5\times$ inference cost, and on SPEED+ repairs 62--80\% of severe flips, while distillation further improves the spacecraft system at no inference cost; aggregation hurts on cluttered YCB-V, so it is an option selected on validation rather than a universal gain (\cref{sec:spp,sec:ablations}). (5) Cross-dataset findings that bound the shared design: translation from the same frozen tokens is accurate on all three general-object benchmarks (T-LESS 88.0\% within 5\,cm, YCB-V 1.6\,cm mean error); geometry fusion helps only where appearance is ambiguous (SPEED+, T-LESS) and costs about $4\times$; household objects in clutter require synthetic training data; and with a synthetic-only detector the spacecraft error doubles on one real domain, so detection, not the heads, limits deployment there (\cref{sec:experiments}). Symmetry-aware losses, test-time augmentation and self-distillation are established ideas; our contribution is their formulation for hierarchical rotation heads on frozen features and the measured evidence above. Fine-tuned state-of-the-art methods remain more accurate on every benchmark we use.
