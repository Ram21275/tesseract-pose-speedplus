# Supplementary figures

Each figure comes as a PDF and a 300-dpi PNG. Generated by `scripts/fig_supplementary.py`; flow per-example data by `scripts/fig_flow_supp.py` (`scripts/run_queue19.sh`).

## Flow experiments (negative result; suits the "refiners that did not fix real flips" section, `tab:negative`)
These use the **EXP-036 clean trees and EXP-042 SO(3) flow, before augmentation and orbit voting** (seed 0), not the final recipe. Flow was never combined with orbit voting. The examples are EXP-107's pre-registered ones (`tables/examples.csv`).

| File | Shows |
|---|---|
| `flow_vs_tree_posterior` | Flow samples vs the tree's top-64 leaves on three images. On the lightbox flip image, a few flow samples reach the true mode but most lie on the wrong one, and the tree is fully on the wrong one. |
| `flow_trajectories` | 16 samples flowing from noise to the posterior |
| `flow_samples_vs_error` | Error against the number of flow samples: the flow's estimate vs an oracle that picks the best sample using GT, vs the tree. The good samples exist but are not selected. |
| `flow_calibration` | Coverage of the flow's confidence regions (seed 0, 10 steps, 32 samples) |
| `flow_and_refiners_vs_orbit` | All flow approaches vs the tree and orbit voting, three domains. Values from `tab:negative`, EXP-111, EXP-127 (tree + orbit) and EXP-117 (distilled + orbit). Mixed seeds counts as in those sources. |
